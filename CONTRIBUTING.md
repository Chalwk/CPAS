# Contributing

This repository supports the Coastal Peaks Air Service website and operations.
Bug reports, corrections, and documentation improvements are welcome.

## Reporting a bug

Open an issue and include:

- Which page or feature is affected
- The exact steps to reproduce
- The browser and OS you're using
- Screenshots if the problem is visual

## Reporting a security issue

**Do not open a public issue for security problems.**

Use the private [Report a vulnerability](https://github.com/Chalwk/CPAS/security/advisories/new)
flow on the Security tab, or see [SECURITY.md](https://github.com/Chalwk/CPAS/blob/main/SECURITY.md)
for the full policy.

## Suggesting a change

Open an issue describing the problem you're trying to solve. For pilot-facing
suggestions (routes, ranks, endorsements), raise them in the CPAS Discord first
so they can be discussed with the community.

## Pull requests

Before opening a PR, make sure:

- The site builds and renders correctly locally
- Content changes match the tone and style of the existing pages
- No personal data, real flight logs, or member information is included
- Links are valid and point to the correct destinations

## Code and content style

- Match the existing Jekyll structure and front matter
- Use sentence case for headings
- Keep aviation terminology consistent with the rest of the site
- Prefer plain English over jargon where possible

## Questions

Ask in the CPAS [Discord](https://discord.gg/NsndXgYfxQ) or open a
[GitHub Discussion](https://github.com/Chalwk/CPAS/discussions).
